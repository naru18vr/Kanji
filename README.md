# まいにち漢字トレーニング

漢検10級〜3級と、小学1年〜中学3年の基本読み書きを練習する静的PWAです。記録は端末へ保存します。

## 収録範囲

- 漢検10〜3級：公式の累積対象1,623字を収録。各字に基本音訓の入力問題を用意しています。
- 小学1〜6年：公式級別漢字表（2020年度からの学年配当）で分類。
- 中学1〜3年：光村図書・令和7年度版の全87単元の漢字一覧PDFから、一覧の見出し字を抽出。教科書単元と既存の3学期年間計画を対応付けます。
- 漢検と教科書は別の範囲です。教科書に含まれる漢検準2級・2級の字を3級とは表示しません。
- 漢検コースは下位級を含む累積範囲、学校コースは学年・学期の範囲を出題します。

収録しているのは基本音訓・漢字の穴埋めと一部の分野練習です。全音訓・全語彙・全出題分野、本番形式と配点の模試は未完成です。このアプリだけで漢検合格可能とは判定していません。ミニ模試は合格判定の根拠にしません。学校のテスト範囲表を優先してください。

## 一次資料とデータ作成

- 漢検公式級別漢字表（2020）：https://www.kanken.or.jp/kanken/outline/data/outline_degree_national_list20200217.pdf
- 漢検公式基準：https://www.kanken.or.jp/kanken/grades/overview/
- 文化庁常用漢字表（2010）：https://www.bunka.go.jp/kokugo_nihongo/sisaku/joho/joho/kijun/naikaku/pdf/joyokanjihyo_20101130.pdf
- 光村図書： https://www.mitsumura-tosho.co.jp/kyokasho/c-kokugo/material1nen （2nen・3nenも参照）

出版社の練習問題文・イラスト・筆順画像は転載しません。字種と単元所属の事実を抽出し、入力問題はアプリで生成します。常用漢字表の音訓と語例を使用します。`tools/build_catalog.py` と `tools/build_school.py` は抽出・再検査用です。単元ごとの参照PDF URLは `src/school-catalog.json` にあります。学期区分は標準的な3学期制の目安です。

## 学習と保存

- 1日5問：期限が来た復習、未学習、読み、書きを選択。開始時に出題順を保存し、回答後の再開で問題を入れ替えません。
- 習得は複数日に分けた想起、30日以上の保持、読み書き両方を必要とします。選択式の正解だけを習得の根拠にしません。誤答後は成功履歴を数え直します。
- 保存キー：`kanji-study-v1`、スキーマ version 1。旧記録を読み込みます。
- 読み書き不能なストレージでも画面を継続し、保存失敗を通知します。
- 引き継ぎはJSONファイルの保存・読み込みに対応。短い記録はリンクでも移せます。
- プリントはブラウザの日本語印刷機能で問題と答えを別ページにします。
